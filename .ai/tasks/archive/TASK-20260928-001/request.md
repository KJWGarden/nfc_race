# User Request

## Original Intent

사용자가 가진 NFC 태그가 NTAG213(고정 URL만 가능)이라 현재의 NTAG 424 DNA(SUN) 전용 태깅으로는 쓸 수 없다. "그럼 일단 QR 병행으로 가능한지" — QR(고정 URL)로도 지점을 인정할 수 있게 하고 싶다.

## Explicit Requirements

1. 방식: 고정 QR을 세션별 스위치로 허용한다 (사용자 선택 "① 고정 QR 세션별 스위치").
   - 스위치를 켠 세션에서만 고정 URL(QR, 그리고 같은 URL을 담은 일반 NFC 태그)을 지점 태깅으로 인정한다.
   - 스위치를 끈 세션은 지금처럼 424 DNA SUN 전용이다.
2. 혼용: 스위치를 켠 세션에서는 424 DNA SUN 태깅과 고정 QR/URL 태깅을 같은 세션에서 섞어 쓸 수 있다 (사용자 선택 "섞어 쓸 수 있음").

## Explicit Constraints

- 이전 Task(TASK-20260927-001)의 사용자 결정 9번("고정 토큰/QR/코드 직접 입력/UID-only 인정 모두 끄기")을 이 스위치 범위에서 바꾸는 요청이다. 스위치가 꺼진 세션의 동작은 바뀌면 안 된다.
- 운영 DB(hosted Supabase)에는 사용자 데이터가 있다. 새 SQL은 새 마이그레이션 파일로만 만들고, 사용자가 SQL Editor로 적용한다.
- git 커밋은 사용자 요청 시에만 한다.

## Open Questions

- 스위치 기본값(새 세션에서 꺼짐/켜짐)은 명시되지 않았다.
- 고정 URL 태깅을 코드 직접 입력(수동 입력칸)으로도 허용할지는 명시되지 않았다.
- NTAG213에 고정 URL을 쓰는 방법(예: 관리자 화면의 Android "NFC에 쓰기" 복원)이 필요한지는 명시되지 않았다.
